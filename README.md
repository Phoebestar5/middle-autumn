# 中秋五味 · 阿加莎主题谜题

本目录保存经过核对的原版静态网页，可部署到 GitHub Pages。

## 保留的原版规则

- 第五题圆环文字为「非肉而冠肉非豆而称豆此蔻辛香亦入药」。
- 首页没有提示按钮，也没有两分钟倒计时。
- 提示只在「五味之外」最终取字页答错后出现。

JavaScript 和 CSS 与 2026-09-16 的原部署 ZIP 完全一致；仅将首页资源地址改成相对路径，以适应 GitHub Pages。

## GitHub Pages 发布

1. 将本目录的内部文件上传到 GitHub 仓库的根目录；保留 assets 子目录。
2. 在仓库 Settings → Pages 中，Source 选择 Deploy from a branch。
3. Branch 选择 main，目录选择 / (root)，保存。
4. 等待 Pages 部署成功，用页面显示的访问地址分享给别人。

这是已编译的静态网页，不需要安装依赖或执行构建。

## 恢复原托管网站

由有服务器管理权限的人备份现有 agatha 目录，再用此目录中的网页文件替换对应文件。
